# 🛒 Amazon Clone
A front-end Amazon Clone website built using **HTML5 and CSS3**. This project recreates the design and layout of Amazon's e-commerce website as part of my journey in learning web development.

## 🌐 Live Demo

**[Click here to view the live website](https://amazon-clone-by-ayushkasaundhan.netlify.app/)**

## ✨ Features

- Amazon-inspired user interface
- Navigation bar with search section
- Product display and shopping categories
- Header and footer sections
- CSS-based styling and layout
- Clean and structured HTML code

## 🛠️ Technologies Used

- **HTML5** – For structuring the website
- **CSS3** – For styling and page layout

## 📸 Project Preview

Visit the live demo to explore the website:

👉 [Amazon Clone Website](https://amazon-clone-by-ayushkasaundhan.netlify.app/)

## 🎯 Learning Objectives

- Recreate a real-world website interface

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
